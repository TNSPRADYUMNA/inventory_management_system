# 📦 Inventory Management System with Face Recognition

An intelligent **Inventory Management System integrated with Face Recognition** to enhance security and operational efficiency.
The system combines **expense tracking, inventory monitoring, and biometric surveillance** into a single platform.

---

## 🚀 Overview

Managing inventory and tracking expenses are essential for organizations. Traditional systems often lack proper security monitoring.

This project introduces a **smart inventory management platform** that integrates:

* 📊 Expense tracking and reporting
* 👤 Facial recognition for inventory access monitoring
* 🔐 Role-based access control (Admin & Manager)
* 📈 Interactive dashboards for analytics

The system uses **ReactJS, Spring Boot, MySQL, OpenCV, and DeepFace** to create a modern and secure solution. 

---

# 🧠 System Architecture

The system follows a **three-tier architecture**:

1. **Frontend**

   * Built using **ReactJS**
   * Provides dashboards, forms, and reports

2. **Backend**

   * Developed using **Spring Boot**
   * Handles APIs, authentication, and business logic

3. **Database**

   * **MySQL** stores user data, expenses, and access logs

4. **Face Recognition Module**

   * Implemented using **Python, OpenCV, and DeepFace**
   * Detects and recognizes faces from CCTV camera feeds

The facial recognition module runs independently and logs entries with timestamps.

# 📚 Implementation Modules

The system consists of six major modules:

### 🔐 User Authentication Module

Handles secure login and role-based access.

### 💰 Expense Management Module

Allows users to add, update, and analyze expense records.

### 👁 Inventory Surveillance Module

Uses CCTV and face recognition to track entry and exit.

### 🤖 Face Recognition Module

Processes camera feeds using **OpenCV and DeepFace**.

### 📊 Dashboard & Analytics

Displays charts and insights for expense tracking.

### 🔗 API & Data Management

Handles backend services and database communication.

These modules work together to provide a complete inventory monitoring system.
